PROJECT: I PAY GHANA — MODERN FINTECH WEBSITE

1. PROJECT OVERVIEW

Design and build a complete, modern, responsive fintech website for I Pay Ghana, a Ghana-focused digital payments and financial technology brand.

The website should communicate trust, simplicity, accessibility, innovation, and financial empowerment. Its visual quality should match the standard of leading African fintech brands, using a clean layout, authentic Ghanaian lifestyle photography, bold typography, and a distinctive green visual identity.

The website must feel like a credible fintech platform built for everyday Ghanaians, small businesses, entrepreneurs, and digitally connected consumers.

Brand name: I Pay Ghana
Industry: Financial technology / Digital payments
Primary market: Ghana
Primary language: English
Currency: Ghanaian cedi (GHS)
Visual direction: Modern African fintech, clean, premium, accessible, and trustworthy.

Important: Treat I Pay Ghana as the brand being designed, not as a copy of M-KOPA. Use the reference design language as inspiration while creating original branding, content, components, and layouts.

Do not invent specific financial products, regulatory approvals, partnerships, transaction capabilities, or guarantees that have not been provided.

Typography

Typography should feature:

UI style

- Pill-shaped buttons.
- Soft, restrained shadows.
- Minimal borders.
- Consistent spacing.
- Clean icons.
- Smooth hover transitions.
- Accessible colour contrast.

19. DESIGN QUALITY BENCHMARKS

The finished website should communicate the following qualities:

Trust: Clear information, professional layout, and restrained visual design.

Simplicity: Users should understand the purpose of I Pay Ghana within seconds.

Local relevance: The imagery, currency, language, and visual details should feel appropriate for Ghana.

Modernity: The site should look like a contemporary fintech brand rather than a generic corporate template.

Conversion: Every major section should guide users toward an appropriate next step.

Consistency: Colours, buttons, typography, card styles, and spacing must follow a coherent design system.

Originality: Use the reference as visual inspiration, not as a template to reproduce pixel for pixel.
